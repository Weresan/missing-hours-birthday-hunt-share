# The Missing Hours — Share Copy

A phone-friendly birthday mystery with an aged-paper storybook look. After three incorrect archive passwords, the page shows a portrait hint labeled “DISCORD USERNAME.” A magic word from the book note unlocks the studio chapter.

Open `index.html` in a browser. Keep the files in this folder together. Progress is stored in that browser.

The static password checks are for the game flow only, not account security. Offline location clues are delivered in handwritten notes.
